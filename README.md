### 👨‍💻 Sobre Mim & Perfil Profissional

Estudante do curso superior de Tecnologia em **Análise e Desenvolvimento de Sistemas (TADS)** no **Instituto Federal do Rio Grande do Norte (IFRN)**. Sou apaixonado por tecnologia e por criar sistemas eficientes.

- 🔭 **Atualmente focado em:** Desenvolvimento de soluções escaláveis no ecossistema **Java (Spring Boot)** e interfaces modernas com **React**.
- 🌱 **Buscando aprimorar:** Arquitetura de software, Clean Code e UX/UI Design.
- 🐧 **Meu Setup:** Entusiasta de otimização de sistemas operacionais e ambiente Linux, utilizando **CachyOS** como plataforma principal de desenvolvimento.
- 💬 **Pergunte-me sobre:** Java, React, Linux e vida de estudante de TI!

### 🚀 Projeto em Destaque

#### 🏠 [ConectLar](https://github.com/joaoPedro158/ConectLar)
Solução de Front-end desenvolvida com foco em acessibilidade e experiência do usuário (UX/UI). O projeto visa facilitar a conexão entre serviços residenciais e usuários, aplicando conceitos modernos de design responsivo.

- **Tecnologias:** JavaScript (ES6+), HTML5 Semântico, CSS3 (Flexbox/Grid).
- **Destaques:** Interface adaptável para dispositivos móveis e otimização de performance.
