## 🚗 Projeto em destaque — Vem Car

<div align="center">
<img src="https://capsule-render.vercel.app/api?type=venom&color=gradient&customColorList=6,11,20&height=150&section=header&text=VEM%20CAR&fontSize=40&fontColor=ffffff&animation=twinkling"/>

<img src="https://img.shields.io/badge/Status-Em%20Desenvolvimento-E68537?style=for-the-badge&logo=vercel&logoColor=white"/>
<img src="https://img.shields.io/badge/Tipo-Projeto%20Acad%C3%AAmico-003C5F?style=for-the-badge"/>
<img src="https://img.shields.io/badge/Plataformas-3%20interfaces-181717?style=for-the-badge"/>

</div>

O **Vem Car** é uma plataforma de mobilidade urbana hiperlocal, pensada para cidades do interior — conectando passageiros e motoristas de forma simples, segura e eficiente, em municípios onde grandes apps de transporte nem sempre chegam.

O projeto é dividido em **três interfaces**: app do Passageiro, app do Motorista e Backoffice web, com um mapa persistente e um Bottom Sheet dinâmico (`discovery → estimate → searching → tracking`) guiando toda a experiência da corrida.

<table>
<tr>
<td width="50%" valign="top">

**🔑 Principais funcionalidades**
- Cadastro de passageiros e motoristas
- Validação de condutores
- Login seguro com JWT
- Solicitação de corrida + estimativa de rota/tarifa
- Histórico de viagens
- Painel administrativo
- Processamento de pagamento digital

</td>
<td width="50%" valign="top">

**🏗️ Stack & Arquitetura**
- Back-end: Java, Spring Boot, Spring Security, JWT, PostgreSQL
- Front-end: React, JavaScript, HTML, CSS
- Modelagem: UML (Casos de Uso, Diagrama de Classes)
- Design System próprio com tokens compartilhados

</td>
</tr>
</table>
