# 🚗 Projeto em destaque

## Vem Car

Sistema de transporte urbano desenvolvido como projeto acadêmico.

O projeto tem como objetivo conectar passageiros e motoristas através de uma plataforma moderna, segura e intuitiva.

### Principais funcionalidades

✅ Cadastro de usuários

✅ Login seguro

✅ Solicitação de corridas

✅ Estimativa de rota

✅ Estimativa de tarifa

✅ Histórico de viagens

✅ Painel do administrador

✅ Painel do motorista

✅ Integração com APIs

### Tecnologias

- Java

- Spring Boot

- React

- PostgreSQL

- REST API

- JWT

- Docker (planejado)
