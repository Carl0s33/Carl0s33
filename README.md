## Sobre

Estudante de **Análise e Desenvolvimento de Sistemas** no **IFRN**, com foco em back-end usando **Java e Spring Boot**. Trabalho também com **React** no front-end, buscando entender o sistema como um todo — da modelagem UML até a API em produção.

Interesse principal em **arquitetura de software**: como organizar camadas, aplicar SOLID e manter um código que continua fácil de mexer seis meses depois. Estou construindo o **Vem Car**, um app de mobilidade urbana, como projeto principal de estudo e portfólio.

## Projeto principal — Vem Car

<div align="center">
<img width="100%" src="https://capsule-render.vercel.app/api?type=rect&color=0:003C5F,100:E68537&height=90&text=VEM%20CAR&fontSize=32&fontColor=ffffff&fontAlignY=60"/>
</div>

Plataforma de mobilidade urbana pensada para cidades do interior, conectando passageiros e motoristas em municípios onde os grandes apps de transporte não têm boa cobertura. Estruturada em três interfaces — app do Passageiro, app do Motorista e Backoffice web — com um mapa persistente e um Bottom Sheet dinâmico controlando o fluxo da corrida (`discovery → estimate → searching → tracking`).

<table>
<tr>
<td width="50%" valign="top">

**Funcionalidades**
- Cadastro e validação de motoristas
- Login seguro com JWT
- Solicitação de corrida com estimativa de rota e tarifa
- Histórico de viagens
- Painel administrativo
- Pagamento digital integrado

</td>
<td width="50%" valign="top">

**Stack do projeto**
- Back-end: Java, Spring Boot, Spring Security, JWT, PostgreSQL
- Front-end: React, JavaScript, HTML, CSS
- Modelagem: UML — Casos de Uso e Diagrama de Classes
- Design system próprio, com tokens compartilhados entre telas

</td>
</tr>
</table>
