## 🚗 Projeto em destaque

<div align="center">

# Vem Car

<img src="https://img.shields.io/badge/Status-Em%20Desenvolvimento-E68537?style=for-the-badge"/>
<img src="https://img.shields.io/badge/Tipo-Projeto%20Acad%C3%AAmico-003C5F?style=for-the-badge"/>
<img src="https://img.shields.io/badge/Stack-Java%20%7C%20Spring%20%7C%20React-181717?style=for-the-badge"/>

</div>

O **Vem Car** é uma plataforma de mobilidade urbana desenvolvida com foco em cidades do interior, buscando conectar passageiros e motoristas de forma simples, segura e eficiente.

A ideia do projeto é criar uma solução hiperlocal, considerando a realidade de municípios menores, onde grandes plataformas de transporte nem sempre atendem bem a população.

### Principais funcionalidades

- Cadastro de passageiros
- Cadastro de motoristas
- Validação de condutores
- Login seguro
- Solicitação de corrida
- Estimativa de rota
- Estimativa de tarifa
- Histórico de viagens
- Painel administrativo
- Integração com serviços externos
- Processamento de pagamento digital

### Tecnologias utilizadas

```text
Back-end
├── Java
├── Spring Boot

└── CSS

Arquitetura
├── UML
├── Casos de Uso
```
